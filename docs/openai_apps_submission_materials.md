## 3. Test prompts + expected responses

Provide these in the submission (the reviewer runs them on web **and** mobile). Each must pass with the flags
above enabled. Expected outputs describe the **structuredContent** the tools return.

1. **Prompt:** "Find a niacinamide serum for dark spots under $30."
   **Expected:** `search_catalog` returns a short list of brand-official products (brand, title, price in USD,
   availability, a canonical `agent.pivota.cc/products/…` link, key actives). No reseller (e.g. ulta.com)
   listings. A one-line summary names the top few.

2. **Prompt:** "Is there evidence that niacinamide helps with dark spots?"
   **Expected:** `get_intel` returns a plain-language summary plus evidence-graded claims, each with citation
   URLs (e.g. PubMed). If no reviewed intelligence exists for the item, it honestly returns none rather than
   guessing.

3. **Prompt:** "Show me a cheaper alternative to [a product from result 1]."
   **Expected:** `get_alternatives` returns alternatives/dupes with a price comparison (e.g. "−25%"),
   tradeoffs, watchouts, and cited evidence.

4. **Prompt:** "Give me the full details and ingredients for [that product]."
   **Expected:** `get_product` (called with the single `product_id` from the search result) returns
   description, ingredient list, images, price, availability, and the canonical Pivota link.

**Reviewer-friendly notes to include:** the app is read-only and anonymous (no login needed); results are
first-party / brand-official only; product intelligence is cited, not generated by the model.

## 6. Submission flow (once the above is ready)

1. Publish the privacy policy; provision `mcp.pivota.cc`; enable the flags.
2. Platform Dashboard → plugin submission portal (`platform.openai.com/plugins`).
3. Enter the MCP server URL → **Scan Tools** (imports the 4 tools + annotations).
4. Fill the form (§1 fields), attach screenshots (§4) and test prompts (§3).
5. Check the confirmation boxes → **Submit for review**.
6. Iterate on any reviewer feedback (server-only fixes deploy without a new review; metadata/tool changes
   need a new version).
